# ChatMobile

一个轻量的 Android 聊天客户端：**你自己提供 API Key**，接任意 OpenAI 兼容服务。

界面对齐 ChatGPT 的读取体验（侧边栏会话、流式输出、Markdown 渲染），
但模型、服务商、思考强度全部由你决定。没有账号体系，没有中转，请求直连你填的地址。

---

## 这是什么 / 不是什么

**是**：一个把「用自己的 Key 跟模型聊天」这件事做顺的手机客户端。
记忆、上下文压缩、工具调用、公式渲染这些通常只在桌面端或网页端才凑齐的东西，这里都有。

**不是**：复刻 ChatGPT 的云服务。没有账号，没有订阅，没有「额度」，
你付的每一分钱都直接给模型服务商。App 本身不收集任何数据，也不包含任何统计 SDK。

---

## 功能

**对话**
- 流式输出、Markdown 渲染（标题 / 列表 / 代码块 / 表格 / 引用）、**LaTeX 公式渲染**
- 每轮自动附加运行时事实（当前时间、时区、语言、位置、工作区状态）
- 侧边栏跟手滑动，会话切换不丢消息（Room 持久化）

**模型**
- 内置 46 家服务商预设，也支持完全自定义的 API 端点
- 一键拉取该端点下所有可用模型
- 思考强度按上游声明的档位选择（不同模型档位不同，不编造）
- 上下文窗口可自行填写（厂家的默认值不等于真正的上限）

**记忆**
- 双层记忆库：长期（永不衰减）+ 近期（按 7 天半衰期衰减）
- 命中自动提升：反复用到的近期记忆会升为长期
- 向量检索：可接云端的 `/embeddings`，也可下载本地 ONNX 模型离线推理
- 记忆条目**随时可查看、可删除** —— 自动抽取跑偏时你能纠正
- 所有参数（抽取频率、单条长度、注入条数、去重阈值、衰减半衰期…）都在面板里可调

**上下文压缩**
- 超出窗口时自动摘要，**原文不删除**，摘要带指针可以回查

**工具调用**
- 内置工具：查时间 / 查位置 / 抓网页 / 存记忆 / 搜记忆
- 每个工具都能单独关掉（关掉的工具连定义都不发给模型，省 token）

**工作区**
- 每个对话可以绑定一个工作区
- 工作区可以在 App 私有目录，也可以是你用系统文件选择器指定的**任意目录**
- 三档权限：仅可查看 / 工作区内修改 / 完全权限
- 共享目录采用「先写私有暂存区、再推送」的方式，避免各厂商 SAF 实现差异

## 安装

从 [Releases](../../releases) 下载 APK 安装。

| 构建 | 包名 | 用途 |
|---|---|---|
| `release` | `com.chatmobile` | 正式版，代码经过压缩混淆 |
| `debug` | `com.chatmobile.debug` | 开发版，带调试入口与诊断日志 |

两个版本**包名不同、可以同时安装**，互不影响数据。

> 最低 Android 8.0（API 26）。只提供 `arm64-v8a`。

首次启动会引导你添加模型：选服务商 → 填 API Key → 选模型。
如果用的是自建或第三方中转，选「自定义模型 API」直接填端点地址即可。

## 从源码构建

需要 JDK 17+ 与 Android SDK（compileSdk 37）。

```bash
git clone <this-repo>
cd ChatMobile

# 把你的 SDK 路径写进 local.properties
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

./gradlew :app:assembleDebug        # 产物在 app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest    # 单元测试
```

Windows 上用 `gradlew.bat`。

**release 构建**需要在 `local.properties` 或环境变量里提供签名信息，否则只能打出未签名包：

```properties
RELEASE_STORE_FILE=/path/to/keystore.jks
RELEASE_STORE_PASSWORD=...
RELEASE_KEY_ALIAS=...
RELEASE_KEY_PASSWORD=...
```

## 项目结构

```
app/                     Android 应用（Compose UI + 集成层）
core-memory/             记忆逻辑（纯 JVM，可独立单测）
core-tools/              工具定义与执行（纯 JVM）
```

`core-memory` 与 `core-tools` 刻意做成**不依赖 Android** 的纯 JVM 模块 ——
衰减曲线、去重、预算分配、LaTeX 转换这些容易出错的纯逻辑，可以脱离设备跑测试。

## 关于密钥

API Key 保存在应用私有的 DataStore 里，**只在发起请求时使用**，不会上传到任何第三方。
App 不含任何统计或埋点。

需要注意：当前版本是**明文存储**（未接 Keystore 加密）。这意味着拿到 root 权限的
设备或备份文件可以被读出。如果你的威胁模型不能接受这一点，请不要在里面填生产环境的 Key。

## 权限说明

| 权限 | 用途 |
|---|---|
| `INTERNET` | 调模型 API |
| `ACCESS_COARSE_LOCATION` | 仅在你允许时读取粗略位置，作为上下文 |
| `READ_EXTERNAL_STORAGE`（仅 API ≤ 32） | 兼容老系统的文件读取；新系统一律走 SAF |

位置权限可以拒绝，拒绝后模型只是收不到位置信息，其它功能不受影响。

工作区访问**不需要任何存储权限** —— 用的是系统文件选择器（SAF），
范围正好等于你手动指定的那个目录，而不是申请全盘访问。

## 已知限制

- 只支持 OpenAI 兼容协议。Anthropic / Gemini 的原生协议暂不支持。
- 文件类工具（读写工作区文件）尚未开放，权限强制层已就绪但还没有接上的工具。
- LaTeX 渲染是把公式转成 Unicode 可读文本，**不是专业排版**。
  复杂公式（多行矩阵、大型分式嵌套）会退化成近似写法，保证能读但不对齐。
